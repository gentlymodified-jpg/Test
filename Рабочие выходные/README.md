# Вольт «Рабочие выходные»

Это корневой файл вольта — краткая карта того, что где лежит и как это устроено.

## Структура

- `Мои тексты эссе/` — первая папка вольта.
  - `Все эссе.md` — индекс, список ссылок на все эссе-хабы.
  - Каждое эссе = отдельная **хаб-заметка** прямо в этой папке (например, `Пример эссе.md`). Внутри хаба — идея, статус, ссылки на источники и связи с другими заметками.
  - `Тексты/` — сюда складываются сами черновики и финальные тексты эссе (по одному файлу на версию/эссе).
- `Шаблоны/` — шаблоны заметок (пока один: шаблон эссе-хаба).

## Как добавить новое эссе

1. Скопировать `Шаблоны/Шаблон - Эссе-хаб.md` в `Мои тексты эссе/Название эссе.md`.
2. Создать сам текст в `Мои тексты эссе/Тексты/Название эссе — черновик.md`.
3. Сослаться на него из хаба через `[[Название эссе — черновик]]`.
4. Добавить строку-ссылку на новый хаб в `Все эссе.md`.

## Дальше будем достраивать

Следующие папки/разделы добавим по мере того, как решим, что нужно (например: Дневник, Проекты, Заметки-источники и т.д.).
